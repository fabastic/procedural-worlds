# Procedural Worlds
Blender add-on that generates complete 3D scenes from a seed. See `CLAUDE.md` for status, architecture and roadmap.

Install: zip the `procedural_worlds/` folder -> Blender > Edit > Preferences > Add-ons > Install from Disk. Panel: 3D Viewport > N > Worlds.
Test: `blender -b -P tools/smoke_test.py -- COASTAL_ISLAND 1`
